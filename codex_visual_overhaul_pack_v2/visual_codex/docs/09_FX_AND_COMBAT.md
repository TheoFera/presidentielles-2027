# 09 — FX combat et pouvoirs

## Style

FX 2D cartoon, courts, lisibles, pas réalistes.

## Coups

Créer :
- petit impact léger ;
- impact fort ;
- poussière de pieds ;
- ligne de vitesse ;
- micro flash de hit.

Le moteur peut ajouter :
- freeze frame ;
- shake ;
sans nécessiter une grosse animation.

## Knockback / KO

- petite traînée ;
- poussière ;
- stars/dizzy si adapté ;
- KO visuellement lisible mais non gore.

## Militants

Attaque verbale :
- bulle/projection de slogan stylisée ;
- contour clair ;
- projectile facile à esquiver ;
- éviter le texte long généré dans l'image.

## Service d'ordre

- impact plus lourd ;
- posture de garde ;
- poussière de raid.

## Spéciaux

### Mélenchon — hologrammes
Réutiliser candidate sprite :
- transparence ;
- teinte ;
- halo ;
- scanlines.

### Le Pen — vague bleu marine
- grande vague graphique horizontale ;
- bord cartoon ;
- lecture immédiate de la direction ;
- pas un liquide photoréaliste.

### Philippe — CRS temporaires
- petit effet d'apparition ;
- barrière visuelle ;
- sprites dédiés.

## Meeting

- petits confettis/ondes de mobilisation ;
- podium/spot temporaire ;
- foule décorative ;
- ne pas masquer les hitboxes des candidats.

## Événements

- incendie bâtiment : fumée/flamme cartoon courte ;
- fermeture administrative : ruban/scellé ;
- crise : icône UI, pas d'effet qui envahit l'écran.

## Budget FX

Limiter les grosses particules.
Sur mobile, réduire automatiquement la densité si FPS faible.
