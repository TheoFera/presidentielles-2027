# 01 — Direction artistique

## Référence maître

`visual_codex/references/STYLE_TARGET.png`

Cette image définit le langage visuel général.

## Style recherché

- illustration 2D de jeu mobile ;
- BD/cartoon française contemporaine ;
- contours sombres assez nets ;
- petits détails dessinés, mais silhouettes faciles à lire ;
- textures peintes légères ;
- lumière chaleureuse ;
- architecture urbaine française crédible mais simplifiée ;
- humour visuel discret ;
- caricature, pas photoréalisme ;
- couleurs claires et vivantes sans devenir néon.

## Priorités

1. Lisibilité gameplay.
2. Cohérence d'ensemble.
3. Caractère satirique.
4. Détails décoratifs.

## Personnages

- légèrement caricaturaux ;
- tête un peu plus grande que réaliste ;
- silhouettes compactes ;
- contours plus marqués que ceux du décor ;
- le joueur doit identifier rôle/faction en moins d'une seconde ;
- personnages publics reconnaissables sans viser la photo réaliste.

## Décor

Le décor peut être détaillé mais :
- ne doit jamais masquer un personnage ;
- ne doit pas concurrencer les couleurs de faction ;
- les façades immédiatement interactives doivent se distinguer des bâtiments de fond.

## Texte

Ne pas intégrer dans les images les textes essentiels :
- noms de bâtiments ;
- montants ;
- événements ;
- boutons ;
- scores.

Créer des panneaux/enseignes vides ou décoratifs, puis afficher le vrai texte dans le moteur.

## Couleurs de faction

Réutiliser les constantes existantes du jeu.

- Mélenchon : rouge.
- Le Pen : bleu marine.
- Philippe : blanc/gris/anthracite.

Les façades de base restent neutres. La faction s'exprime par :
- enseigne ;
- bandeau ;
- petits drapeaux ;
- affiches ;
- éclairage ;
- accessoires.

## Ce qu'il faut éviter

- pixel art ;
- anime/manga ;
- rendu 3D ;
- peinture réaliste ;
- personnages trop grands ;
- bâtiments occupant toute la hauteur ;
- hyper-détails illisibles sur téléphone ;
- logos et textes générés illisibles ;
- arrière-plans trop contrastés ;
- effets volumétriques qui masquent les hitboxes.
