# 14 — Variantes architecturales des bâtiments selon le biome

## Règle absolue

**Chaque type de bâtiment/site doit avoir une identité architecturale différente dans chacun des 6 biomes.**

Il est interdit de prendre un unique sprite de bâtiment et de le recopier dans toute la carte avec seulement une recoloration.

La règle est :

**même fonction + même gabarit de gameplay + même point d'interaction + architecture adaptée au biome.**

Le joueur doit reconnaître immédiatement le type de site tout en sentant immédiatement dans quel biome il se trouve.

## Ce qui doit rester constant entre les 6 variantes

Pour un même type de site :
- footprint/emprise au sol similaire ;
- hauteur dans la plage autorisée ;
- ancre au sol identique ;
- position de la zone d'interaction stable ;
- porte/point focal lisible ;
- emplacement réservé à la signalétique politique ;
- hiérarchie visuelle du type de bâtiment ;
- hitbox et gameplay inchangés.

## Ce qui doit varier selon le biome

- matériaux ;
- façade ;
- toit ;
- fenêtres ;
- mobilier immédiat ;
- végétation ;
- niveau de densité urbaine ;
- état/ancienneté du bâti ;
- type d'enseigne neutre ;
- petits éléments décoratifs cohérents avec le territoire.

Les variations doivent être architecturales, pas seulement chromatiques.

## Ce qui doit varier selon le propriétaire

Le propriétaire ne change pas l'architecture principale. Il ajoute :
- bandeau ;
- petites affiches ;
- drapeau ;
- accents colorés ;
- lumière/activité ;
- overlay QG si nécessaire.

Mélenchon = rouge.
Le Pen = bleu marine.
Philippe = blanc/gris/anthracite.

## Ce qui doit varier selon le niveau

Le niveau n'agrandit pas brutalement le bâtiment. Il ajoute des signes fonctionnels :
- équipement ;
- antenne ;
- affichage ;
- éclairage ;
- mobilier ;
- activité visible.

Les upgrades doivent rester lisibles sans casser la silhouette.

# Matrice architecturale

## 1. Local de campagne / Permanence / QG

### Bobo
Petite boutique/ancien café ou local associatif gentrifié : grande vitrine, façade colorée mais élégante, vélo/porte-affiche, intérieur chaleureux. Le QG peut recevoir davantage de banderoles et de lumière.

### Banlieue
Local en pied d'immeuble : béton/enduit, rideau métallique, vitrine simple, hall ou dalle à proximité, affichage plus brut. Reste propre et lisible, pas de caricature dégradante.

### Périurbain / Usine
Petit bureau de zone commerciale/artisanale : bardage léger, enseigne rectangulaire, parking/plots, façade fonctionnelle, garage ou entrepôt discret en arrière-plan.

### Campagne
Ancienne boutique de bourg ou petite maison de village reconvertie : crépi/pierre, volets, enseigne simple, jardinière, banc ou place de village.

### Retraités
Petit pavillon associatif ou local de quartier très entretenu : haies taillées, jardinières, façade claire, stores, environnement calme.

### Quartiers riches
Rez-de-chaussée en pierre ou petit bureau élégant : pierre de taille, encadrements fins, laiton/bois, marquise discrète, grille ou jardinières haut de gamme.

## 2. Financement

### Bobo
Petit espace de coworking/collecte : verrière, affichage de campagne discret, mobilier moderne visible derrière la vitrine.

### Banlieue
Bureau associatif/comptable de pied d'immeuble : façade pratique, guichet, panneaux neutres, éclairage direct.

### Périurbain
Bureau dans une petite zone d'activité : bardage, parking, enseigne sobre, accès fonctionnel.

### Campagne
Ancien bureau de notaire/assurance ou petite agence de bourg : façade traditionnelle, porte centrale, plaques neutres.

### Retraités
Agence très ordonnée de type mutuelle/association : façade claire, stores, plantes, mobilier rangé.

### Quartiers riches
Bureau de conseil/finance de petite taille : pierre, verre, plaque discrète, intérieur plus haut de gamme.

## 3. Tour de communication

### Bobo
Petit studio média / local créatif avec antenne de toit, panneaux lumineux et éléments de production audiovisuelle.

### Banlieue
Local technique/média au pied ou sur la terrasse d'un immeuble avec mât compact et parabole.

### Périurbain
Petit bâtiment technique/entrepôt média avec mât plus industriel, câbles, antennes, containers techniques.

### Campagne
Petite station radio/relai local : bâtiment bas, mât fin, clôture légère, végétation autour.

### Retraités
Local de communication communautaire bien entretenu : bâtiment sobre avec antenne discrète et panneau d'information.

### Quartiers riches
Agence média élégante : façade chic avec antennes/parabole intégrées discrètement, écrans intérieurs raffinés.

## 4. Site Service d'ordre / Cabinet administratif

Le **site physique de base** varie avec le biome. La fonction finale dépend du propriétaire.

### Bobo
Petit local polyvalent urbain, vitrine, réserve latérale.

### Banlieue
Local de stockage/association en pied d'immeuble, rideau métallique et porte de service.

### Périurbain
Petit hangar/bureau logistique, garage, zone de chargement.

### Campagne
Dépendance de maison communale / ancien atelier, porte large, matériaux traditionnels.

### Retraités
Petit local associatif ordonné, entrée claire, rangements visibles.

### Quartiers riches
Bureau annexe élégant, porte cochère ou petite façade de services.

**Mélenchon/Le Pen :** overlays de casiers, équipements, gilets, bâtons, signalétique logistique.

**Philippe :** overlays de dossiers, plaques, classeurs, bureaux, scellés/administration.

## 5. Imprimerie neutre

### Bobo
Atelier risographie/sérigraphie ou imprimerie créative : vitrines colorées, rouleaux, affiches abstraites sans texte lisible.

### Banlieue
Copy-shop/imprimerie de quartier : devanture simple, photocopieuses et piles de papier visibles.

### Périurbain
Petit atelier d'impression semi-industriel : bardage, porte atelier, palettes de papier.

### Campagne
Imprimerie de bourg traditionnelle : ancienne devanture, presses/boîtes visibles, bois et crépi.

### Retraités
Petite imprimerie/papeterie très ordonnée : vitrine claire, stores, présentoirs.

### Quartiers riches
Papeterie/imprimerie haut de gamme : devanture élégante, papier fin, boiseries, vitrines sobres.

## 6. Salle de meeting neutre

### Bobo
Maison de quartier / petite salle culturelle / loft événementiel.

### Banlieue
Salle polyvalente, gymnase de proximité ou maison de quartier.

### Périurbain
Salle municipale moderne ou grande salle proche d'une zone commerciale/industrielle.

### Campagne
Salle des fêtes de village clairement identifiable.

### Retraités
Club-house / salle associative municipale très entretenue.

### Quartiers riches
Petit auditorium, salon de conférence ou salle culturelle chic.

Pendant un meeting, la salle reste neutre structurellement ; seules les décorations temporaires du candidat apparaissent.

## 7. Institut de sondage neutre

### Bobo
Studio d'études/sondages type agence créative, verrière et écrans.

### Banlieue
Bureau moderne de terrain en rez-de-chaussée, panneaux/cartes visibles sans texte essentiel.

### Périurbain
Bureau d'études dans une petite zone tertiaire, façade fonctionnelle.

### Campagne
Petite antenne d'étude installée dans un ancien local communal/commercial.

### Retraités
Bureau d'études sobre, très ordonné, proche d'un environnement municipal/associatif.

### Quartiers riches
Cabinet de sondage/conseil élégant, verre/pierre, écrans et graphiques stylisés.

# Transitions et bâtiments

Un bâtiment situé dans une sous-zone de bord reste principalement du style de son biome, mais son **environnement immédiat** peut annoncer le biome voisin :
- matériaux secondaires ;
- végétation ;
- mobilier ;
- densité ;
- arrière-plan.

Ne pas créer une septième architecture "transition" sauf nécessité. Le raccord doit surtout être géré par le décor autour du site.

---

# Production recommandée

Pour chacun des 7 types de sites :
1. produire un gabarit fonctionnel ;
2. produire 6 bases architecturales (1 par biome) ;
3. définir des zones d'overlay normalisées ;
4. ajouter propriétaire/niveau/état par layers runtime quand possible ;
5. éviter de générer une image complète pour chaque combinaison propriétaire × niveau × état si des overlays suffisent.

Cela donne au minimum **42 bases architecturales de site** (7 types × 6 biomes), même si certains services ne sont pas présents dans tous les biomes dans la carte finale.

Le manifest peut contenir les 42 variantes afin que le pipeline dispose d'une bibliothèque complète, mais le runtime ne charge que les variantes réellement utilisées par `world_layout`.

---

# Critères d'acceptation

Pour valider les bâtiments :
- une capture des 6 variantes d'un même type doit montrer clairement 6 architectures différentes ;
- malgré cela, le type doit rester reconnaissable sans texte ;
- aucune variante ne doit modifier la hitbox ;
- le neutre existe avant capture ;
- la capture ne spawn pas une nouvelle structure ;
- les couleurs politiques doivent être des overlays, pas la seule différence architecturale ;
- les niveaux restent lisibles mais modestes ;
- chaque bâtiment doit s'intégrer au décor du biome sans rupture de style.
