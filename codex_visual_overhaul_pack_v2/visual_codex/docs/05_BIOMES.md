# 05 — Les 6 biomes et 18 sous-zones

Le monde est une boucle horizontale continue.

## 1. BOBO / Paris 19e

### bobo_a_canal
- canal/quai ;
- vélos ;
- terrasses ;
- arbres urbains ;
- architecture parisienne mixte ;
- graffitis propres/affiches culturelles.

### bobo_b_place
- place de quartier ;
- cafés ;
- librairie/épicerie ;
- pistes cyclables ;
- petits immeubles.

### bobo_c_mixte_vers_banlieue
- architecture plus mixte ;
- logements collectifs plus récents ;
- moins de cafés ;
- skyline de tours au loin ;
- prépare Banlieue A.

## 2. BANLIEUE

### banlieue_a_cite_vers_bobo
- collectif résidentiel ;
- tours au loin ;
- petits commerces ;
- reste quelques éléments urbains du Bobo C.

### banlieue_b_marche
- marché populaire ;
- commerces ;
- placette ;
- mobilier urbain ;
- forte vie de rue.

### banlieue_c_pavillons_vers_periurbain
- densité en baisse ;
- petits pavillons ;
- garages ;
- véhicules ;
- petits ateliers ;
- prépare zone artisanale.

## 3. PÉRIURBAIN / USINE

### periurbain_a_pavillons_artisanal
- pavillons modestes ;
- zone artisanale ;
- petits entrepôts ;
- parkings ;
- rond-point en décor.

### periurbain_b_usine
- usine/entrepôts ;
- cheminée ou silos stylisés ;
- route plus large ;
- grillages ;
- panneaux industriels.

### periurbain_c_sortie_vers_champs
- dernières halles industrielles ;
- terrain vague ;
- champs visibles ;
- ligne d'arbres ;
- prépare la campagne.

## 4. CAMPAGNE

### campagne_a_entree_village
- champs ;
- route ;
- ferme/entrée de village ;
- quelques hangars au loin.

### campagne_b_centre_village
- mairie/place ;
- boulangerie ;
- café ;
- église éventuelle en fond ;
- maisons basses.

### campagne_c_vers_retraites
- champs qui diminuent ;
- pavillons ;
- haies très entretenues ;
- jardins ;
- prépare Retraités A.

## 5. RETRAITÉS

### retraites_a_pavillons
- lotissement ;
- pelouses parfaitement tondues ;
- haies ;
- petites clôtures ;
- bancs.

### retraites_b_square_pharmacie
- pharmacie ;
- square ;
- salle associative ;
- marché calme ;
- résidence classique.

### retraites_c_residences_aises
- pavillons plus grands ;
- résidences haut de gamme ;
- rues plus propres ;
- jardins plus travaillés ;
- prépare Riches A.

## 6. QUARTIERS RICHES

### riches_a_residentiel
- maisons bourgeoises ;
- grilles ;
- voitures haut de gamme stylisées ;
- végétation très entretenue.

### riches_b_avenue_boutiques
- boutiques élégantes ;
- façades pierre ;
- terrasses chics ;
- avenue arborée.

### riches_c_haussmann_vers_bobo
- Haussmann / institutions ;
- densité urbaine qui remonte ;
- vélos et cafés réapparaissent ;
- transition vers Bobo A.

## Principes communs

- aucun biome ne doit être une caricature ethnique ;
- la caricature sociale passe par architecture, mobilier, véhicules, activités, accessoires ;
- le sol et l'horizon restent compatibles entre sous-zones ;
- les sites interactifs restent lisibles et distincts du décor.
