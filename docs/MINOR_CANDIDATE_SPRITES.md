# Sprites des candidats secondaires

Les caricatures d’Arthaud, Dupont-Aignan, Retailleau et Roussel ont été retravaillées à partir de dix photos par candidat : voir [révision des ressemblances](MINOR_CANDIDATE_LIKENESS_V2.md). Les prompts ci-dessous décrivent la première version, conservée pour historique.

Six planches de douze poses créées avec l’outil ImageGen intégré. Références : sprites originaux de Mélenchon, Marine Le Pen et Édouard Philippe. Images RGBA conservées sans retouche dans `assets/generated/minor-candidates/`.

Les rectangles et les points d’appui sont mesurés par `node scripts/measure-minor-sprites.mjs` dans `src/presentation/minor-sprite-atlases.js`. Une seule échelle par candidat, calculée depuis la pose debout : les poses accroupies et couchées restent naturellement plus petites. Le moteur nettoie les faibles valeurs alpha comme pour les autres planches. Le dessin de secours reste disponible pendant le chargement ou en cas d’échec.

Ordre : repos, deux phases de marche, course, deux coups de poing, coup de pied, charge, blessure légère, recul, KO, persuasion. Deux dessins de marche et deux coups de poing peuvent être proches visuellement ; il s’agit d’animations courtes à deux poses.

Aperçu du rendu réel : `/src/presentation/minor-sprite-preview.html`. L’ancienne page `minor-preview.html` conserve les maquettes et leur export.

Validation : 22 tests ciblés (`visual-assets`, `minor-candidates`) réussis ; 72 poses contrôlées dans Chrome sans erreur JavaScript ; `npm run build` réussi. Capture : `artifacts/minor-sprites/galerie.png`.

No captions, no grids, no ground shadows, no effects, no scenery. Subject: Raphaël Glucksmann, recognizable long face and prominent nose, thick tousled dark brown hair, short dark stubble beard, navy suit, white open collar shirt, small pink lapel/pocket accent, dark shoes. No glasses, no necktie, no scarf.
